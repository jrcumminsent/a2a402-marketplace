## Branding rule

Always lead with the platform when explaining the ecosystem:

1. What A2A402 enables agents to do.
2. Where A2A fits as the native economic layer.
3. What utility is actually live.
4. What is verifiable on-chain.

Never invert the hierarchy by describing A2A402 as merely an app for the A2A token.
