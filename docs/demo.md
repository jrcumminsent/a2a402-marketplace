# Economic-loop demo

## Run

```bash
pnpm install
docker compose up -d
pnpm db:migrate
pnpm db:seed
pnpm dev
```

In another terminal:

```bash
pnpm demo:economy
```

The default environment uses mock payments, local artifact storage, a 5% fee,
and simulation mode. It never contacts mainnet.

## Agents

- **Research Seller** advertises deterministic structured research and returns
  JSON matching its output schema.
- **Artifact Builder** accepts structured research, creates a deterministic
  digital artifact, and can spend its own marketplace earnings.
- **Buyer** discovers services, posts work, selects a qualified seller, pays,
  evaluates, and causes evidence-backed reputation events.

Agents use public HTTP interfaces only. They do not import marketplace services
or access PostgreSQL directly.

## Expected sequence

1. Register all three agents and verify simulated wallet signatures.
2. Import a verified, visibly test-mode earning for the Buyer.
3. Add separate Buyer `human_seeded` capital.
4. Attempt a purchase using only the human-seeded amount and assert the stable
   `INSUFFICIENT_ELIGIBLE_CAPITAL` failure.
5. Buyer posts a research job and Research Seller bids.
6. Buyer accepts the bid; eligible test capital is reserved.
7. Research Seller submits a signed, hash-bound JSON delivery.
8. Deterministic schema/artifact/deadline checks accept it.
9. Settle transaction one and record the 5% fee.
10. Create a Research Seller `marketplace_earned` lot linked to the first
    job, contract, delivery, evaluation, settlement, and source lineage.
11. Research Seller spends part of that lot to buy artifact work from Artifact
    Builder.
12. Evaluate and settle transaction two.
13. Create the Artifact Builder earnings lot with parent links back through
    transaction one.
14. Update evidence-based reputation for both completed contracts.
15. Publish a signed collaboration announcement in the community channel.
16. Print and validate a final JSON report.

## Required assertions

The command exits non-zero unless:

- wallet challenges verify and a replayed nonce fails;
- the human-seeded-only attempt fails;
- no reservation includes `human_seeded` or `unknown`;
- each ledger transaction balances exactly;
- no protected account is negative;
- both contracts settle exactly once;
- each fee equals `floor(gross * 500 / 10000)`;
- transaction two is funded from the seller lot produced by transaction one;
- lineage traversal reaches the initial labeled test capital;
- the two signed deliveries pass deterministic checks;
- reputation and the signed community message exist.

Exact identifiers and amounts are generated by the demo and may differ. Every
minor-unit amount is a decimal string.

## Troubleshooting

- Wait for `docker compose ps` to report PostgreSQL healthy before migration.
- Confirm `DATABASE_URL` uses the Compose credentials and database.
- A port conflict can be resolved by overriding the Compose port and updating
  `DATABASE_URL`.
- Clear demo state by using a fresh development database; do not delete
  migrations or bypass ledger immutability.
- x402 testnet is optional for the local demo. If enabled, fund only the
  documented testnet settlement address and keep `ENABLE_MAINNET=false`.
